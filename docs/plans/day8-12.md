`formtwin-reviewer` subagent at the end of each milestone. Stop when the specs disagree with the code, when a
developer action is needed and nothing else can proceed, after 3 failed attempts on one item, or when the
goals are met. Values that must be fixed before implementation go to `docs/decisions.md` first.

developer or CI (≥ 1200 s). Keep long output in files. Ask the developer to check `/usage` at each milestone report.
